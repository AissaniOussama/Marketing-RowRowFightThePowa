# Hero-Bild einfügen

Lege dein Bild einfach hier als `hero-bg.jpg` ab (gleicher Name, gleiche Endung) —
`docs/assets/hero-bg.jpg`. Sobald die Datei existiert, taucht sie automatisch als
Hintergrund der Hero Section auf (Referenz sitzt in `docs/css/style.css`, Klasse `.hero-bg`).

Andere Endung (`.png`, `.webp`, ...) oder anderer Name? Kurz sagen, dann passe ich
die eine Zeile in `style.css` an.

Empfehlung fürs beste Ergebnis: ein eher dunkles/kontrastreiches Bild, quer (mind.
1600×700px), da oben ein dunkler Verlauf drüberliegt, damit der weiße Headline-Text
lesbar bleibt.
